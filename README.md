# Ouf-Farmacy-Manager — «إدارة صيدلية عوف»

لوحة إدارة ومراقبة لصيدلية عوف (موقع PWA + APK أندرويد)، بنفس تقسيمة «إدارة جبهالي»، ومربوطة على **نفس شيت الصيدلية** اللي بيشتغل عليه تطبيق العميل وتطبيق الطيار.

## اللي شغال دلوقتي
| القسم | الوصف |
|---|---|
| **الإدارة والتعيين ← الطيارين** | طلبات التعيين / المعينين / المرفوضين. تغيير حالة الطلب (منتظر/مقبول/مرفوض) وحالة الطيار (يعمل/موقوف مؤقتاً/موقوف نهائي) وتعديل كل بياناته. |
| **الإدارة والتعيين ← العملاء** | قائمة العملاء + بحث + تغيير «حالة العميل» (جيد/موقوف) و«حالة البرنامج» (يعمل/حذف = إلغاء تثبيت التطبيق من جهاز العميل). |
| **متابعة الطيارين** | الطلبات: جديدة / مقبولة / تجهيز / توصيل / تم التسليم (آخر 150). في «مقبولة» تقدر تحوّل الطلب لطيار آخر متاح (الطيار القديم بيتسجل «سابق» زي التطبيق). |
| الصفحة الشخصية / حول | زي جبهالي. |

## «قريبًا» (جوه قوايمهم لحد ما نظبطهم)
الإدارة والتعيين ← **الموظفين** و**المحلات المتعاقدة** · **متابعة الموظفين** (دعم الطلبات/شخصي/العملاء/المتعاقدين) · **متابعة المتعاقدين**.

## الإعداد (مرة واحدة)
1. **الشيت:** افتح مشروع Apps Script جديد (script.google.com) والصق `backend/manager.gs`، شغّل `setupManagerSheet` (بتعمل ورقة «إدارة صيدلية عوف»)، وبعدين **Deploy ← New deployment ← Web app** (Execute as: Me / Anyone) وانسخ الرابط.
2. **الإعدادات:** في `www/config.js` حط الرابط في `MANAGER_URL`.
3. **GitHub:** اعمل مستودع Public اسمه `Ouf-Farmacy-Manager`، ارفع كل المحتويات (مع `.github`)، وفعّل **Settings ← Pages ← Source: GitHub Actions**.
4. **APK:** **Actions ← Build Android APK ← Run workflow** وحمّل `ouf-manager-apk` من Artifacts. التحديثات بتتثبت فوق القديمة (المفتاح ثابت).
5. **أول مسؤول:** سجّل من التطبيق («سجل كمسؤول إداري جديد») ← افتح ورقة «إدارة صيدلية عوف» وغيّر «حالة الطلب» بتاعه لـ **مقبول**.

> لو عدّلت `manager.gs` بعد كده: Deploy ← Manage deployments ← Edit ← New version (نفس الرابط).

## ملاحظات
- **الأمان:** كل طلب للسكربت بيتحقق من رقم المسؤول + توكن (بيتغير لو الباسورد اتغير) وحالة الحساب. باسوردات المسؤولين والطيارين متخزنة نص عادي في الشيت زي باقي النظام، فسيب الشيت خاص بيك.
- **تحويل الطيار من اللوحة** بيغيّر الشيت مباشرة، والطيار الجديد بيشوف الطلب في تطبيقه (بيسأل كل 5 ثواني)، لكن **مفيش إشعار Push** ليه (الإشعارات بتتبعت من مشروع «اوردارس»).
- الألوان واللوجو نفس جبهالي (أحمر على داكن). الحزمة `com.muradpharmacy.manager`.
- الورق المستخدم: «إدارة صيدلية عوف» (جديدة) + «الطيارين» + «العملاء» + «الطلبات» + «الطلبات المكتملة» (موجودين).
